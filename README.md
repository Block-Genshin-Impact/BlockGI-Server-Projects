> 本仓库只负责索引项目，不存放具体 Mod、客户端或启动器源码。

## 目录维护

新增项目时，请在对应分类中添加一行，并保持以下格式：

```text
| 项目名 | 简短说明 | [进入仓库](组织仓库链接) |
```

如果项目类型暂时不明确，先放入最接近的分类，后续再调整。
